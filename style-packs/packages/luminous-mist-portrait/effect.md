# 朦胧发光人像 · 可调效果提示词

## 效果目的

让**照片已有的亮处**呈现柔和的外溢光晕，同时保留人物五官、肤色体积、衣料和背景的可读层次。默认方向是法式朦胧发光胶片人像；森系环境、黑柔、金柔、白柔是按照片与用户要求选择的变化项。可以独立使用，叠加现有风格只是可选能力。本包是给修图 Agent 的提示词和真实教程参考照片的**原站链接**，不包含照片文件；也不是固定滑杆 XMP 或实体滤镜的精确光学复制。

## 调用时收集或推断的输入

```text
用户想要：默认法式发光 / 黑柔 / 金柔 / 白柔；森系开/关；轻/中/强；是否另有风格包。
原片：RAW 或已渲染、Profile、当前白平衡/曝光、裁切、输出色域；有无已拍入的柔雾滤镜。
画面：真实亮源与亮边在哪里；人物脸、发丝、白衣和暗部在哪里；背景是草地、森林、室内还是夜景。
限制：肤色要多自然、背景允许变多少、细节和黑位要保留多少。
能力：当前 Lightroom/Runtime 可写可回读的参数与蒙版；是否另有合法的像素级高光泛光工具。
```

缺字段记 `unknown`；先用可见原图判断。用户未指定强度时从**轻**开始；若没有人物，仍可用亮区与背景层次规则，但不凭空添加人像肤色处理。用户说“保持原风格”时先记录原风格的光色、黑位和背景锚点，再只动与本效果有关的区域。

## 执行提示词：观察 → 分层编辑 → 回读比较

1. **建立基线。**保留原图/当前风格版和同尺寸可回看的渲染。检查明亮处是否已有裁切、脸是否欠曝、白衣是否还有纹理、黑发/树荫是否有密度。已有镜前柔雾时从更小增量开始。
2. **判亮源。**有窗光、逆光发丝、灯点或明亮叶缘时，以它们为光晕中心；光晕要有亮核及附近渐弱的范围。无可信亮源时只做柔和胶片色或轻背景空气感；不要声称做出了自然强泛光。
3. **先处理基础色调。**按原片调曝光、白平衡、亮暗关系，检查肤色受光与阴影。胶片感可小幅来自曲线、色彩分级和颗粒，但这些不替代光晕。有人像与植被时，调整绿色要先看黄绿、深绿和肤色之间的关系；不把人物染绿。
4. **局部塑光。**优先在亮源附近使用当前工具已确认可写/回读的明度范围、径向/线性渐变或手动蒙版。可小步改亮区亮度、局部微反差、暖冷与周围背景的分离；人物脸、眼、唇、白衣纹理及远背景各自检查。需要把暖光放在人物背后时，若工具能正确创建蒙版，可从光区减去人物；边缘须实际看覆盖图。
5. **区分柔和与泛光。**Lightroom 的 Texture、Clarity、Dehaze、曲线和局部亮度只能近似柔雾、反差与亮区强调；不能保证真实“高光越过物体边缘”的像素级散射。若用户指定要达到参考图 01 那样明显的外溢光晕，可在已授权的像素级工具中从原图高光建立窄/宽两级柔光；当前只有 LR 时诚实说明是观感近似，不用全图失焦假装完成。
6. **最后看整图。**检查整幅的光源方向、肤色自然度、白衣/天空端点、叶片层次、暗部支点与颗粒。已叠加风格时，将“风格版 → 加本效果版”成对比较，避免误把原风格变化算成本效果。若肤色需更严格保护，可另读肤色效果包，但不要重复执行两次全局白平衡。

## 用户可以怎样继续修改

一次只推进用户点名的维度，然后给出新的前后对比；“更梦幻”先询问或按画面最显著的一个问题选择**一种**维度，不同时提高亮度、柔化、暖度和颗粒。

| 用户说 | Agent 应解释并优先改变 | 要保留 |
|---|---|---|
| “高光更发光” | 让已有亮源附近的光晕更明显或范围更宽；先局部，必要时说明 LR 上限 | 亮核、脸和白衣层次 |
| “更朦胧，但人清楚” | 背景/远景微反差与空气层，少动脸部和眼睛 | 主体轮廓、发际与背景深度 |
| “更法式胶片” | 在当前光色上微调低反差曲线、克制的暖冷关系和细颗粒 | 真实肤色与高光核心 |
| “更黑柔” | 灯点/逆光晕更柔，暗部仍有重量 | 黑发、树荫、夜景黑位 |
| “更金柔” | 只沿实际暖光和光晕增加蜂蜜金色 | 肤色不过橙，冷色区域可存在 |
| “更白柔” | 扩大中高光柔和区域，光色偏中性，暗部可稍轻 | 白衣与脸的纹理和体积 |
| “更森系” | 按现有植被选择冷灰绿、暖黄绿或深绿，不一律套绿 | 皮肤不泛绿，叶片不荧光 |
| “肤色自然／背景少动” | 缩小全局颜色变化，优先人物与亮区局部选区 | 脸颈手关系、背景远处和蒙版边缘 |
| “弱一点／太假” | 回到上一可接受版，撤回最后加重的那一个维度，再小步尝试 | 用户已认可的光线方向和风格 |

## 停止与交付

- 明显脸部失焦、发际蒙版露边、白衣/天空连成纯白块、背景变成平灰幕、金柔令整张图泛黄、黑柔令黑位漂灰、绿色侵入皮肤时减弱或回退。
- 如果需要的光晕强度超过当前可写工具的能力，就保留最佳 LR 近似版，并说明差距来自空间散射；不得虚构已完成的 PS 步骤。
- 交付时说明使用的主方向与可选变化、关键可变项、最有效的用户下一句话，以及当前照片中没有使用的分支。对照必须同裁切、同尺寸、同输出色彩条件。没有 Lightroom 真机成对检验时只说“候选提示词”，不说“已验证可复现”。
