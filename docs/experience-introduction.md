# 扩展 Agent 操作 Lightroom 的能力

## 工具介绍

ToneRelay 是面向 Lightroom Classic 的本地 MCP 工具套件。Agent 理解修图目标并决定下一步；ToneRelay 通过 MCP 与 Lightroom 插件执行操作、回读结果。

你不需要把 Lightroom 放在前台，也不需要让 Agent 通过截图、鼠标和界面控件完成操作。

> Catalog 级批量执行 · 真实原彩渲染回读 · 图像测量与对比 · 后台多方案试色

相比 Agent 直接操作 Lightroom 界面：省去反复截图、视觉定位和逐步确认，直接处理 Catalog 并回读实际结果，减少等待与 Token 消耗。

## 从一句话开始

你可以直接说出想要的结果：

> 保留夕阳的暖意，让人物肤色自然，背景不要太抢。

Agent 会把你的描述拆成步骤，ToneRelay 负责把明确的操作交给 Lightroom。你可以先看真实渲染，再决定继续调整、保留这个版本，或者换一个方向。

## 它能做什么

### 批量操作 Catalog

一次组织多项明确操作，批量处理照片或创建候选版本。实际写入由受控队列完成，每个结果都有对应的版本和执行记录。

### 回读真实原彩渲染

参数提交不等于结果已经生效。ToneRelay 会读取 Lightroom 实际产生的渲染结果和回读状态，把发生了什么交还给 Agent。

### 测量和对比图片

单张图片可以转换成亮度、色彩、直方图和空间采样等可比较的特征。

两张已经保存的图片可以进行并排预览和数值对比，用来比较编辑前后、基准与候选，或两个不同方向的版本。工具提供事实和差异，最终哪一张更合适，仍由 Agent 和你来判断。

### 后台试出多个方向

不确定应该往哪边调时，可以先提交多个明确的参数方向。候选会在后台逐个渲染，你可以稍后回来查看进度和结果，再保留最适合的一版。

## 不需要从一排滑块开始

MCP 为每个已支持的参数提供名称、含义、范围、输入条件和限制。你不必先记住 Lightroom 的字段名，也不必让 Agent 从界面猜测滑块作用。

这些参数说明告诉 Agent“可以怎样填写”，但不会替你决定“这张照片应该调多少”。照片的目标、参考图和最终审美判断仍然属于你和 Agent。

## 你可以这样使用

### 把一张照片调到位

说清楚想要的明暗、颜色和情绪，再根据真实结果继续细调。

> 保留夕阳暖意，让人物肤色自然，阴影不要死黑。

### 跟着参考图找感觉

选一张喜欢的参考，让调整朝同一种光线和色彩关系靠近。

> 把这张阴天旅行照调成清爽、克制的彩色负片感觉。

### 让一组照片看起来像一组

给同一趟旅行、婚礼或日常记录建立连贯的观感。

> 统一室内、户外和混合光下的色彩倾向，但保留每张照片自己的光线。

### 先试几种，再选一张

面对拿不准的照片，先比较几种方向，再保留最喜欢的版本。

> 同一张夜景分别试胶片、干净数码和电影感，给我三张真实结果。

## 两种修图方式

自己慢慢试，适合你已经知道每一步要怎么调：打开照片、推拉滑块、反复比较。

和 ToneRelay 一起，适合你知道想要什么画面，但不想从一排滑块开始：说出目标、看结果，再继续细调。

## 安装介绍

复制安装提示词，发给你正在使用的 Agent，例如 Codex 或 WorkBuddy。Agent 会先确认客户端和本机环境，再按官方说明接入 ToneRelay。完整提示词单独保存在 [install-prompt.md](install-prompt.md)，网页上的复制按钮也读取这份文件。

安装并验证完成后，再回到风格画廊选择模板和照片；之后直接说出你想要怎样的结果。

## 常见问题

### 需要先懂 Lightroom 参数吗？

不需要。Agent 可以先理解你的目标，MCP 会提供参数的含义、范围和限制。你可以从照片效果开始描述。

### ToneRelay 会覆盖原片吗？

编辑工作以虚拟副本和版本记录为边界，结果需要通过 Lightroom 的实际回读确认。开始前仍应按照自己的 Catalog 备份习惯操作。

### 模板和普通预设有什么不同？

模板提供风格方向和参考上下文。Agent 会结合当前照片、你的目标和真实渲染结果决定下一步，而不是把一个固定参数表盲目套到所有照片上。

### 图片对比会自动告诉我哪张最好吗？

不会。对比工具返回预览、测量和差异；哪一种更符合你的目标，仍由 Agent 和你共同判断。

### 怎么开始？

先安装并登录一个 Agent，复制提示词发给它。确认 ToneRelay 与 Lightroom 已连接后，选择一张照片和一个风格方向，直接说出你想看到的结果。
