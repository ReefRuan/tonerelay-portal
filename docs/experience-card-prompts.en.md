# Example Prompts for Comparison Cards

These are general starting prompts for visitors to copy and send to an Agent, not verbatim transcripts of the conversations in the page’s screenshots. Continue the conversation based on your own photos and goals. The page copies only each section’s body, not its heading or this introduction.

## 01 Conversational editing

Please help me edit the currently selected photo in Lightroom Classic. First confirm which photo you found, then ask what look I want. Make a first version on a virtual copy based on my goal, return a preview actually rendered by Lightroom, and briefly explain what changed. After seeing it, I will tell you what to adjust next. Iterate based on my feedback rather than deciding on a final version for me.

## 02 Batch photo selection

Please help me organize a set of photos in the current Lightroom Classic folder. First confirm the scope and existing marks. If my selection criteria are unclear, ask me first. Then inspect each photo and suggest star ratings or flags based on sharpness, duplication, and the criteria I provide. Do not delete photos or overwrite existing marks. Write the clearly decided marks back to Lightroom in a batch, then list the photos processed, skipped, and needing my review.

## 03-A Subject-mask refinement

Please help me refine the currently selected photo in Lightroom Classic. First confirm which photo it is, then ask what I want to change and what should stay unchanged. Choose global adjustments based on that goal. If the person needs separate treatment, use subject masks supported by the current version and check the mask coverage in a new preview. Make a first version on a virtual copy, then return actual Lightroom-rendered before-and-after previews and parameter readbacks. I will point out more details after seeing them; please keep adjusting based on my feedback.

## 03-B Reference-based color grading

I will provide reference images. First inspect their colors and lighting, then confirm which Lightroom Classic photos to process. Start with one sample photo: adjust a virtual copy, return a preview actually rendered by Lightroom, and explain which reference you used and what changed. Once I confirm the direction, process the other photos individually. Adjust each photo for its own lighting rather than applying the same parameter set to all of them.
