# 对比卡示例提问

这些是供访客复制、发给 Agent 的通用起手话术，不是页面截图中真实对话的逐字稿。请根据自己的照片和目标继续对话。页面只复制各小节正文，不复制标题或这段说明。

## 01 对话修图

请帮我调整 Lightroom Classic 当前选中的照片。先确认你找到的是哪张照片，再问我想要什么效果。根据我的目标在虚拟副本上做第一版，带回 Lightroom 实际渲染的预览，并简要说明改了哪里。我看图后会继续告诉你哪里要调整；请根据反馈迭代，不要替我决定最终版本。

## 02 批量选片

请帮我整理 Lightroom Classic 当前目录中的一组照片。先确认处理范围和已有标记；如果我的选片标准还不清楚，先问我。然后逐张看图，按清晰度、重复程度和我给出的标准提出星级或旗标建议。不要删除照片，也不要覆盖已有标记。把明确的标记批量写回 Lightroom，最后列出已处理、跳过和需要我复核的照片。

## 03-A 主体蒙版细调

请帮我细调 Lightroom Classic 当前选中的照片。先确认是哪张，问我想改哪里、哪些地方要保持原样。根据目标选择全局调整；如果需要单独处理人物，使用当前版本支持的主体蒙版，并通过新预览检查覆盖效果。先在虚拟副本做一版，带回 Lightroom 实际渲染的前后预览和参数回读。我看图后会继续指出细节，请按反馈再调整。

## 03-B 参考图调色

我会提供参考图，请先看它们的颜色和光线，再确认要处理的 Lightroom Classic 照片范围。先选一张照片做样片：在虚拟副本上调整，带回 Lightroom 实际渲染的预览，并说明参考了哪张图、改了哪些地方。等我确认方向，再逐张处理其他照片；每张都按自身光线调整，不要把一套参数直接套给所有照片。
