# ToneRelay 卸载提示词

请完整卸载 ToneRelay 的客户端接入、MCP 服务、Bridge 和 Lightroom 插件；保留其他 MCP 配置、照片、Catalog、预设、个人数据和可恢复备份。

优先读取安装清单，核对实际组件、归属与使用它们的客户端，备份相关配置。共享组件仍被其他客户端使用时，列出影响并询问是否继续；同一范围已获授权则连续完成。若我只要求卸载指定客户端，仅移除它的接入。使用已安装版本支持的入口，按三步处理：

macOS 统一配置版本先定位 config.json，再读取独立的 install-manifest.json；配置备份不作为另一份生效配置。清单应覆盖专用安装根、实际数据根、下载、日志、缓存/临时目录、备份，以及根外的客户端配置和 Lightroom 登记。新 macOS 安装的预期根为 `~/Library/Application Support/ToneRelay`，实际位置仍以记录与现场核对为准；旧安装可能使用外部数据。不得根据仓库名称、工作目录或安装时的 `source-root` 删除开发仓库；只有安装器创建且归属已确认的安装源码副本才可删除。核对符号链接的实际目标，外部个人数据与共享解释器不纳入删除。

Windows 不照搬 macOS 命令或假设具备同样的清单与进程保护。旧版整目录卸载会删除其中的 data；先核对并备份个人数据，再逐项移除软件，不直接执行整目录删除。

1. 移除已授权客户端的 ToneRelay 接入，核对未完成作业，按身份和安装归属停止各客户端/会话的 MCP 实例及 Bridge。有界等待退出并复查是否重新拉起；端口关闭不能单独证明进程停止。
2. 移除 Lightroom 插件注册或受管链接，必要时正常退出并重开 Lightroom；禁用不算删除，软链接只处理链接本身。
3. 按清单删除已确认归属的软件、安装源码副本、下载、缓存和临时文件，清理已登记的外部宿主接入；清理前确认进程已停止。保留个人数据、运行数据与可恢复备份，并报告剩余根目录内容及其位置；删除运行数据与备份须另有明确授权，不为追求空目录直接删除整根。核对旧外部路径的残留，归属不明时说明具体路径与待核对项，不笼统宣布完成。

卸载检查只读取客户端实际接入/工具列表、进程、注册和文件；不再调用会提交 Lightroom 作业的安装状态探测。只有无法确认客户端刷新时才重连或新建会话；证据充分即停止检查，不能观察的层标记待验证。

只卸载不重装；明确要求“卸载并重装”时，在同一任务核对卸载基线，再从已授权的固定来源安装并用新会话只读验证。公开安装不默认使用内部源码。真人确认卡住时说明动作、原因和最小操作，保存断点，不绕过保护。
