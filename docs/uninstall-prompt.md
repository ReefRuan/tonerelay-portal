# ToneRelay 卸载提示词

请卸载 ToneRelay，并保留其他 MCP 配置、照片、Catalog、预设和个人数据。

先核对卸载范围、当前客户端和 ToneRelay 实际安装组件，并备份相关配置。只卸载当前客户端时仅移除它的 ToneRelay 接入；完整卸载才继续处理无人使用的共享 Runtime 和 Lightroom 插件。使用已安装版本支持的卸载方式，沿用本次授权连续完成。

分别核对客户端条目移除、Lightroom 插件禁用/注册移除、已确认归属的受管文件和进程处理；禁用不能称为文件已移除，客户端断开不能称为 Runtime 已卸载。共享组件仍被其他客户端使用或文件归属不明时保留并明确报告。移动或删除软链接只处理链接本身，保留可恢复备份。正常重启需要重启的应用，逐层报告真实结果。

实际创建客户端新会话并确认 ToneRelay 连接已移除；不能创建或观察时，说明限制、给出可复制检查请求和断点交接，标记待验证。

只要求卸载时不要重装。如果我明确要求“卸载并重装”或“干净重装验收”，请在同一任务完成卸载、新会话卸载基线核对、从本次已授权来源安装和另一个新会话的只读验证。公开安装先核对可访问的固定官方发行物；不要默认使用内部源码。真人授权卡住时，说明具体动作、原因和最小操作，保存进度；不得关闭安全保护绕过确认。
